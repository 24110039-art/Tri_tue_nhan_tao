# Tri_tue_nhan_tao
# 🤖 VACUUM.AI — Pathfinding Simulation

Chương trình mô phỏng robot hút bụi sử dụng các thuật toán tìm kiếm AI trên lưới 2D.

## 📌 Thông tin
- **Môn học:** Trí Tuệ Nhân Tạo
- **Trường:** HCMUTE
- **MSSV:** 24110039

## 🧠 Thuật toán được cài đặt

| Nhóm | Thuật toán |
|------|-----------|
| Tìm kiếm mù | BFS1, BFS2, DFS1, DFS2, IDS |
| Tìm kiếm có thông tin | Greedy, A* |
| Tìm kiếm cục bộ | Simulated Annealing (SA), Local Beam Search (LBS) |
| Môi trường không xác định | AND-OR Graph Search |
| Bài toán thỏa mãn ràng buộc | CSP Backtracking, CSP Forward Checking |

## 🎮 Cách chạy

```bash
/opt/homebrew/bin/python3 demo.py
```

## ✨ Tính năng
- Giao diện đồ họa Cyberpunk với PyQt6
- Robot di chuyển animation theo từng bước
- So sánh hiệu suất tất cả thuật toán sau mỗi lần chạy
- Tùy chỉnh kích thước lưới, đặt ô bụi và chướng ngại vật
- Log chi tiết từng bước của từng thuật toán
